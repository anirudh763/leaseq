LeaseQ

Privacy

LeaseQ is a local queue operator interface. It does not create a hosted account or send telemetry from this page.

Browser data

  • Optional local profiles store an email identifier, a salted PBKDF2 password verifier, and small saved settings/drafts in this browser. Passwords are not stored. Saved work is not encrypted.
  • The API bearer token is held in page memory only. Reloading or logging out clears it; it is not placed in local storage, URLs, the service-worker cache or feedback diagnostics.
  • The recovery simulation is local to this tab until you explicitly save it into a profile. Quick-start progress is namespaced by guest or profile. The synthetic demo does not call the queue API.
  • The service worker caches only this app’s public HTML, CSS, JavaScript, fonts, icons and bundled sample text. It does not cache API/auth responses, jobs, payloads, results or tokens.

Network and sharing

When you explicitly connect, the browser sends authorized API requests to the LeaseQ server that serves this dashboard. That server receives the request data needed for the action. The server operator’s retention and access policy is outside this local profile.

Sharing a job link includes only the current app URL and job number. It does not include a payload, result, filter text or API token. Recipients need network access and their own authorization. Feedback opens a prefilled draft at the public LeaseQ GitHub issue page only after you review and choose Open GitHub draft; it is not sent automatically.

Clearing browser site data, browser eviction or device loss may remove local profiles and work. Export important information before clearing site data. No cloud recovery is available.
