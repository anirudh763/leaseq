Security & offline data

The service worker is scoped to /dashboard/. It caches public application files and the bundled sample only. Queue API responses and mutations always use the network and are never queued for later replay.

What works offline

CapabilityAvailability
Landing, deterministic local lease model, synthetic demo, bundled sample/help and local themeAvailable after the shell has been prepared and its cache remains available.
Local profile signup/login and saved browser preferencesAvailable when app assets, Web Crypto and browser storage are available. Reload opens the landing page; a profile must be unlocked again. The API token is cleared on reload.
First visit or first install while offlineRequires a network visit first. Offline readiness is shown only after all required shell assets are cached and the worker controls this page.
Real jobs, health, submit, cancel, requeue, schedules and server metricsRequires network access to the authorized LeaseQ API and a valid server-issued token where required.
Offline submit/cancel/requeue replay, local worker or PostgresUnsupported. No mutation is stored for later replay; the service worker cannot run the server or worker.

Local profiles and removal

Profile passwords are verified with Web Crypto PBKDF2-HMAC-SHA-256 (600,000 iterations and a random per-profile salt). This does not encrypt saved work. The shared API token is page-memory-only and is not stored in the service-worker cache. Only explicitly saved, bounded profile preferences and drafts persist in this browser.

Cache storage can be unavailable or evicted. The app verifies pinned SHA-256 digests for every required shell file; an evicted file is restored only if the network copy exactly matches this release. A mismatch is reported instead of mixing builds or returning an HTML page pretending to be JavaScript or an image. Reconnect and check readiness to repair the shell.

You can also remove site data for this app’s exact origin and /dashboard/ service-worker scope in browser settings. The button above deletes only local-storage keys beginning with leaseq:, caches beginning with leaseq-dashboard-shell-, and the registration scoped to this app. It does not delete jobs on your server or another app’s origin data.
